# youla-mvp images

Public image hosting for generated, reviewed listing illustrations. This repository contains no price feeds, credentials, or source database.

`images/test.jpg` is a neutral connectivity check.

## iPhone 17 Pro Orange illustrations

The product visual used in `images/new-len-iphone-17-pro/` is by [Eugen Prostakov](https://commons.wikimedia.org/wiki/File:IPhone_17_Pro.png), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). TelMart changed its size and composition in the listing images. The caption-free versions retain this attribution, source URL, license URL and modification notice in JPEG EXIF metadata. They illustrate the model and are not photographs of a specific item in stock.

## Other TelMart model illustrations

The specification cards for the other 15 models were created with OpenAI imagegen for TelMart. Each render was prompted for its model family and color, then combined with the selected memory, SIM type and manager price from the full 18 November 2026 price packet. They are AI illustrations; their exact appearance has not been verified against a physical device. They are not photographs of stock. The repository serves image files only; the separate `youla-new-feed` repository serves listing data.
